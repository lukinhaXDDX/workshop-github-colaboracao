# Como contribuir

1. Abra uma issue no repositório original com título, contexto e critérios de aceitação.
2. Faça fork, clone e crie uma branch com nome descritivo, por exemplo `add-apresentacao-01`.
3. Edite **somente** o arquivo reservado a você em `participantes/`.
4. Faça commit claro, publique a branch e abra PR para a `main` do repositório original.
5. No PR, explique as alterações, como verificar os critérios e escreva `Closes #N` usando o número correto da issue.
6. Revise o PR de sua dupla com comentários específicos e respeitosos; responda aos comentários recebidos.
7. Aguarde a aprovação e integração pelos mantenedores. Não faça merge do próprio PR durante a atividade.

## Critérios do arquivo
- Título e nome ou apelido.
- Seção `Sobre mim` com 2–3 linhas.
- Seção `Dica` indicando uma ferramenta e sua utilidade.

## Boas práticas
Não envie dados pessoais sensíveis. Evite editar arquivos compartilhados. Não use mensagens vagas como `teste` ou `ok` para commits.
